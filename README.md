## ⚡ Quick Start

### 1. Launch the Local Server
```bash

git clone https://github.com/smjaveed786/T-Minus-Countdown-AI-Powered-Deadline-Planner.git
cd T-Minus-Countdown-AI-Powered-Deadline-Planner

# Start the zero-dependency Node server
node server.js
```

### 2. Open in Any Browser
Navigate to:
```
http://localhost:3000
```

## 🖥️ Key Features

### 1. Dual Screen Architecture
- **Desktop Monitor Mode (16:9 4K UHD):** Expands into a 3-column panoramic command dashboard:
  - **Left Wing:** Mission Progress (80%), Velocity & Buffer metrics, Today's Priority, and Motivational Quote.
  - **Center Stage:** Monumental 3D Floating Glass Countdown (with 480px rotating energy orbits).
  - **Right Wing:** Milestone Switcher, 3 Master Gates, and the 6-Stage Backward Timeline HUD.
- **Mobile Smartphone Mode (9:16 OLED):** Clean vertical lock screen with titanium chassis and dynamic island.
- **Fullscreen Display:** One-click ambient countdown mode for monitors, TVs, and wall displays (Hotkeys: `M` to toggle monitor/phone, `F` for fullscreen).

### 2. Dual Procedural 4K Wallpaper Exporters
- **`[ ⬇ Export 4K 16:9 ]`**: Generates and downloads an ultra-crisp **3840×2160** desktop monitor wallpaper with active countdown numerals, progress, and glass specular highlights baked in.
- **`[ ⬇ Export 9:16 ]`**: Generates and downloads the **1440×3120** smartphone lock screen wallpaper.

### 3. Six-Stage Backward Planning Timeline
Engineered backward from the **November 23, 2026 at 11:59 PM PT** hard deadline with built-in 3-hour buffer:
- **01 — GOAL DEFINITION:** Scope crystallization & rubric deconstruction (`Nov 17 • 6PM PT`)
- **02 — RESEARCH & PREP:** Tooling setup, verified dependencies, wireframes (`Nov 18 • 8PM PT`)
- **03 — MAIN EXECUTION:** Core architecture build-out (80% done) (`Nov 21 • 8PM PT`)
- **04 — TESTING & POLISH:** Responsive testing, performance optimization (`Nov 22 • 10PM PT`)
- **05 — FINAL REVIEW:** Line-by-line rubric audit & documentation (`Nov 23 • 6PM PT`)
- **06 — SUBMISSION GATEWAY:** Portal upload & receipt verification (`Nov 23 • 9PM PT`)

### 4. Zero-Asset Synthesized Audio System
Built-in Web Audio API synthesizer generates subtle sci-fi UI clicks, frequency chimes, and tick pulses with zero external audio assets.
